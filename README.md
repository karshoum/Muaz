# معرض الراقي الهندسي للأثاث والديكور

متجر ويب متكامل لمعرض أثاث وديكور في السودان — واجهة عربية (RTL) بهوية ذهبية/كحلية،
طلب مباشر عبر واتساب، ولوحة تحكم للمدير مع التصوير بالكاميرا وتفريغ خلفية الصور بالذكاء الاصطناعي.

> 📘 **للبدء السريع ودليل الإعداد الكامل بالعربية:** [`docs/SETUP-AR.md`](docs/SETUP-AR.md)

---

## التشغيل

```bash
npm install
npm run dev          # http://localhost:3000
```

يعمل الموقع فوراً بلا أي إعداد، على تخزين محلي داخل المتصفح (IndexedDB) مع بيانات تجريبية.
لتفعيل قاعدة البيانات السحابية ونشر منتجاتك للعملاء، اتبع [`docs/SETUP-AR.md`](docs/SETUP-AR.md).

- الموقع: `/` • لوحة التحكم: `/admin` • كلمة المرور التجريبية: `admin1234`

---

## المزايا

**للعملاء**
- بانر متحرك، شبكة الأقسام الستة، وشبكة منتجات متجاوبة بالكامل (Mobile-First)
- بحث عربي ذكي (يوحّد الألف والياء والتاء المربوطة) وتصفية بالقسم وترتيب بالسعر/التقييم
- السعر بالجنيه السوداني، كود القطعة، والتقييم على كل بطاقة
- **زر "اطلب عبر واتساب"**: ينسخ اسم القطعة والكود والسعر إلى الحافظة، ثم يفتح واتساب
  برسالة منسّقة جاهزة للإرسال إلى رقم المعرض

**للمدير (`/admin`)**
- شاشة دخول محمية (Supabase Auth عند التفعيل)
- إدارة كاملة للمنتجات: إضافة، تعديل، حذف، نشر/إخفاء
- إعدادات مباشرة: أرقام واتساب، بيانات التواصل، شبكات التواصل، العملة، شريط الإعلانات
- **مصدران للصور**: رفع من معرض الجهاز (متعدد + سحب وإفلات) أو التقاط بالكاميرا
- **تفريغ خلفية اختياري** لكل صورة على حدة، مع حفظ النسخة الأصلية وإمكانية التراجع

## البنية

```
app/            صفحات Next.js (App Router) — الموقع العام و /admin
components/     ui · layout · home · product · admin
lib/
  data/         طبقة البيانات: واجهة موحّدة + محوّل Supabase + محوّل محلي (IndexedDB)
  whatsapp.ts   تطبيع الأرقام السودانية وبناء رسالة ورابط الطلب
  format.ts     تنسيق السعر، توليد كود القطعة، تطبيع البحث العربي
  image.ts      ضغط الصور وتحويلها
  background-removal.ts   استيراد ديناميكي لمكتبة تفريغ الخلفية
supabase/schema.sql   الجداول وقواعد الأمان ومخزن الصور
tests/          unit (Vitest) · e2e (Playwright)
```

### طبقة البيانات

كل التطبيق يستورد من `lib/data` فقط. المحوّل يُختار تلقائياً:

| الحالة | المحوّل | النتيجة |
|---|---|---|
| مفاتيح Supabase مضبوطة | `supabase-adapter` | البيانات سحابية ويراها كل العملاء |
| المفاتيح فارغة | `local-adapter` | IndexedDB داخل المتصفح — للتجربة فقط |

الانتقال بين الوضعين لا يتطلب تعديل أي مكوّن — فقط إضافة المفاتيح في `.env.local`.

### تفريغ الخلفية

`@imgly/background-removal` تُستورد **ديناميكياً داخل معالج الضغط فقط**، فلا تدخل حزمة
أي صفحة. من يختار "الحفظ كما هي" لا يُنزّل منها بايتاً واحداً، وصفحات العملاء لا تمسّها إطلاقاً.

## الاختبارات

```bash
npm run test        # وحدات: واتساب، التنسيق، طبقة البيانات، المكوّنات
npm run test:e2e    # تكامل: التجاوب، رحلة الطلب، لوحة التحكم، الكاميرا
```

**اختبارات الوحدة (Vitest + Testing Library)** — 68 اختباراً تغطي:
تطبيع أرقام الهاتف السودانية بكل صيغها · تشكيل رسالة ورابط واتساب والترميز الصحيح ·
نسخ بيانات القطعة ومسار فشل النسخ · تنسيق السعر وتوليد الأكواد وتطبيع البحث العربي ·
عمليات CRUD على IndexedDB والبيانات التجريبية والإعدادات · عرض بطاقة المنتج.

**اختبارات التكامل (Playwright)** — تعمل على ثلاثة مقاسات (جوال/لوحي/سطح مكتب) وتغطي:
انعدام التمرير الأفقي على كل الصفحات · اتجاه RTL · رحلة العميل حتى رابط الواتساب والتحقق
من محتوى الرسالة · دخول المدير وإضافة منتج وظهوره للعملاء · تعديل رقم الواتساب وانعكاسه ·
**فتح الكاميرا والتقاط صورة** (بكاميرا وهمية) · رفع صورة من الملفات وحفظها بدون تفريغ مع
التأكد من عدم تحميل نموذج الذكاء الاصطناعي · سلوك التفريغ عند تعذّر تنزيل النموذج.

اختبار التفريغ الحقيقي بالنموذج الكامل موسوم `@slow` ويُشغّل يدوياً:

```bash
RUN_SLOW_AI_TESTS=1 npx playwright test camera-background
```

إن كان لديك متصفح Chromium مثبّت مسبقاً ولا تريد تنزيل آخر:

```bash
PLAYWRIGHT_CHROMIUM_PATH=/مسار/chromium npm run test:e2e
```

## ملاحظات أمنية

- المفتاح المستخدم في الواجهة هو `anon` فقط؛ الحماية الحقيقية من قواعد RLS في `supabase/schema.sql`
  (قراءة عامة للمنشور، وكتابة للمدير المصادَق فقط). لا تستخدم `service_role` إطلاقاً.
- حارس `/admin` في الواجهة لتحسين التجربة فقط — الاعتماد الأمني على RLS.
- كلمة مرور الوضع التجريبي تعمل فقط حين تكون مفاتيح Supabase فارغة، وتظهر لافتة تحذير
  داخل اللوحة في هذه الحالة. لا تنشر الموقع للعامة قبل تفعيل Supabase.
- `.env.local` مستبعد من Git.
