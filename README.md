# الموقع الشخصي — معاذ محمد كرشوم حسن

موقع شخصي ومهني عربي بالكامل (RTL أصيل)، مبني بـ **Next.js 16 (App Router) + TypeScript + Tailwind CSS**.

---

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
```

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج |
| `npm run start` | تشغيل نسخة الإنتاج بعد البناء |
| `npm run typecheck` | فحص أنواع TypeScript بلا بناء |

المتطلبات: Node.js 20 أو أحدث.

---

## أين تُعدَّل الأشياء

### كل المحتوى في ملف واحد: `lib/data.ts`

لا يوجد نص عربي مكتوب داخل أي مكوّن. لتحديث سيرتك أو إضافة مشروع، عدّل هذا الملف وحده:

| ما تريد تغييره | أين |
|---|---|
| الاسم، المسمّى، البريد، الهاتف، الموقع | `profile` |
| المسمّيات في تأثير الكتابة | `profile.roles` |
| الإحصاءات (سنوات الخبرة، عدد المشاريع…) | `stats` |
| الملخّص المهني والفلسفة | `profile.summary` / `profile.philosophy` |
| الخبرات والتعليم | `timeline` |
| المشاريع | `projects` |
| المهارات | `skillGroups` |
| روابط القائمة العلوية | `navLinks` |

الأنواع معرّفة في `lib/types.ts`، فأي حقل ناقص أو خاطئ يظهر كخطأ عند `npm run typecheck`.

### إضافة مشروع جديد

أضف عنصرًا إلى `projects` في `lib/data.ts`:

```ts
{
  id: 'my-project',
  title: 'اسم المشروع',
  tagline: 'وصف من سطر',
  description: 'فقرة قصيرة…',
  category: 'web',              // education | web | content | ai
  features: ['ميزة ١', 'ميزة ٢'],
  stack: ['Next.js', 'PostgreSQL'],
  accent: { from: '#0F2A43', to: '#C9A227' },   // ألوان هوية المشروع
  preview: 'paradise',          // مفتاح المعاينة (انظر أدناه)
  url: 'https://example.com',   // احذفه إن لم يوجد رابط عام
  statusLabel: 'منصة قائمة',    // يُعرض بدل زر «عرض مباشر» عند غياب url
}
```

**المعاينات ليست صورًا.** كل معاينة واجهة مصغّرة مرسومة بـ CSS داخل
`components/ui/BrowserMockup.tsx` بألوان المنتج الحقيقية — تبقى حادّة في أي دقة
وبصفر طلبات شبكة. لإضافة معاينة جديدة: اكتب مكوّنًا هناك، سجّله في `previews`،
وأضف مفتاحه إلى `PreviewKind` في `lib/types.ts`.

### الألوان والثيم

كل الألوان متغيّرات CSS في `app/globals.css` تحت `:root` و`.dark` — لا قيم لونية
خام داخل المكوّنات. لتغيير هوية الموقع، عدّل `--accent` و`--accent-2`.

> ⚠️ `--cta-from` / `--cta-to` منفصلان عمدًا عن `--accent`، ويجب أن يبقيا داكنين
> بما يكفي للنص الأبيض. السبب: `--accent` يُفتَّح في الوضع الداكن ليُقرأ فوق خلفية
> داكنة، ولو اشتُقّ منه تدرّج الأزرار لهبط النص الأبيض فوقها إلى **١٫٨:١**.

### السيرة الذاتية

`public/cv-maaz-karshoum.pdf` **ملف نائب مؤقت**. استبدله بالسيرة الحقيقية مع
**الإبقاء على الاسم نفسه** كي يستمر زر التحميل في العمل.

## نموذج التواصل

لا يوجد ادّعاء نجاح كاذب. السلوك:

1. تحقّق فوري في المتصفح برسائل خطأ عربية.
2. عند الإرسال يُنادى `POST /api/contact`.
3. **بلا إعداد** يردّ المسار بالحالة `501`، فتفتح الواجهة تطبيق البريد لدى الزائر
   برسالة مُهيّأة وتخبره بذلك صراحةً.
4. **مع الإعداد** تُرسل الرسالة فعلًا وتظهر رسالة نجاح حقيقية.

للتفعيل: انسخ `.env.example` إلى `.env.local` واضبط `CONTACT_WEBHOOK_URL` على
نقطة نهاية تقبل JSON بالحقول `name` و`email` و`message` (Formspree أو Zapier أو
دالة خادم خاصة بك).

## ما جرى التحقق منه

نتائج قياس فعلي على نسخة الإنتاج، لا تقديرات:

**سلوكيًا — ٢٤/٢٤:** تصفية المشاريع · فتح الروابط في تبويب جديد مع `noopener` ·
غياب الروابط الميتة · تبديل الثيم وبقاؤه بعد إعادة التحميل · تحقّق النموذج
و`aria-invalid` · فتح القائمة الجانبية ونقل التركيز إليها · حبس التركيز ·
الإغلاق بـ `Escape` مع إعادة التركيز وفكّ قفل التمرير · تعطّل الحركة فعليًا تحت
`prefers-reduced-motion` · `dir="rtl"`/`lang="ar"` · عنوان `h1` واحد · معالم
دلالية · `aria-label` على كل زر أيقوني · JSON-LD من نوع `Person` · رابط تخطّي
المحتوى.

**تباينًا:** كل النصوص تحقّق WCAG AA في الوضعين، بقياس اللون بعد فكّ `color-mix`
وطبقات الزجاج الشفافة. أدنى قيمة مقيسة **٤٫٧٤:١** (نص أصفر فوق بطاقة فاتحة)
و**٥٫٣٦:١** للنص الأبيض على أسوأ طرف من تدرّج الأزرار.

**أداءً:** صفر طلبات إلى نطاقات خارجية (الخطوط مستضافة ذاتيًا) · ‏CLS ≈ `0.0006`
· ‏FCP ≈ `350ms` · ١٨ طلبًا · لا تمرير أفقي عند `360px` أو `768px` أو `1440px` ·
صفر أخطاء في طرفية المتصفح · `npm audit` نظيف.

## ملاحظات قبل النشر

- **أرقام الإحصاءات** (`stats` في `lib/data.ts`) تقديرية — راجعها. الرقم الأدق أقوى
  من الأكبر.
- **مشروعا «الراقي للأثاث» و«صرح» ينتظران التفاصيل** — أُضيفا كرابطين مباشرين
  بناءً على طلبك لكنهما لم يُدرَجا بعد كبطاقتَي مشروع كاملتين لأن الوصول للموقعين
  محجوب من بيئة التنفيذ. أرسل وصفًا موجزًا لكل موقع (الوظيفة، أبرز الميزات،
  والتقنية إن عرفتها) لإضافتهما دون افتراضات.
- **`profile.siteUrl`** مضبوط الآن على `https://maazkarshoum.vercel.app` (النطاق
  الفعلي المنشور). إن رُبط نطاق مخصّص لاحقًا، حدّثه ليطابقه.
- **البريد معروض نصًّا** في قسم التواصل والتذييل، ما قد يجذب رسائل مزعجة. إن أزعجك
  ذلك، احذف بطاقة البريد من `channels` في `components/sections/Contact.tsx` واترك
  النموذج والواتساب.
- لا توجد شعارات جامعة كردفان أو الجهات الحكومية أو المؤسسات في الموقع — أسماؤها
  نصًّا فقط، تفاديًا لمسائل حقوق الملكية.
- **مشروعا «النظام الإداري التعليمي» و«الأرشيف التاريخي»** عُرضا بلا اسم الجهة
  ولا رابط، بناءً على طلبك حفاظًا على خصوصيتهما — العنوان والمعاينة المصغّرة كلاهما
  خاليان من أي اسم أو رابط يدلّ عليهما.

## النشر على Vercel

المستودع جاهز للنشر كما هو. تم التحقق من أن `npm ci && npm run build` — وهو
بالضبط ما تنفّذه Vercel — ينجح من تثبيت نظيف.

### الخطوات

1. ادخل [vercel.com/new](https://vercel.com/new) وسجّل الدخول بحساب GitHub.
2. اختر مستودع `karshoum/Muaz` واضغط **Import**.
3. لا تغيّر شيئًا في شاشة الإعداد — تكتشف Vercel تلقائيًا:
   - Framework: **Next.js**
   - Build Command: `npm run build`
   - Output Directory: `.next`
   - Install Command: `npm install`
4. **Environment Variables** — اتركها فارغة إن كنت تريد سلوك نموذج التواصل
   الافتراضي (فتح تطبيق البريد). لتفعيل الإرسال من الخادم أضف
   `CONTACT_WEBHOOK_URL` بقيمة نقطة النهاية التي تستقبل الرسائل.
5. اضغط **Deploy**. البناء يستغرق نحو دقيقة.

### بعد أول نشر

- **الفرع الإنتاجي:** المستودع فرعه الوحيد والافتراضي هو
  `claude/maaz-portfolio-website-lblw8d`، فتنشره Vercel إنتاجًا مباشرةً بلا دمج.
  إن أعدت تسمية الفرع الافتراضي لاحقًا إلى `main`، حدّث
  *Settings → Git → Production Branch* ليطابقه.
- **النطاق:** بعد ربط نطاقك في *Settings → Domains*، عدّل `profile.siteUrl` في
  `lib/data.ts` ليطابقه — يُستخدم في الرابط الأساسي (canonical) وبطاقات
  المشاركة، وتركه على القيمة الافتراضية يعطي روابط مشاركة خاطئة.
- **السيرة الذاتية:** استبدل الملف النائب `public/cv-maaz-karshoum.pdf` قبل أن
  يزور الموقع أحد.

### مستضيفات أخرى

Node.js ‏20+ بـ `npm run build && npm run start`.
