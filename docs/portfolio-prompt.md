## 0) الدور والمُخرَج المطلوب

أنت **Principal Frontend Architect + Lead UI/UX Engineer**. مهمتك بناء موقع شخصي/مهني (Portfolio) لـ **معاذ محمد كرشوم حسن** — عربي بالكامل، RTL أصيل، متجاوب، وبمستوى بصري يليق بمهندس واجهات محترف.

**المخرَج:** مشروع **Next.js 14 (App Router) + TypeScript** كامل وقابل للتشغيل بـ `npm i && npm run dev` دون أي تعديل يدوي — لا شيفرة ناقصة، ولا `// TODO`، ولا مكونات وهمية.

اكتب الملفات بالترتيب التالي، كل ملف في كتلة كود مستقلة معنونة بمساره:

```
app/layout.tsx              ← <html lang="ar" dir="rtl">, الخطوط, الـ metadata
app/page.tsx                ← تجميع الأقسام فقط
app/globals.css             ← Tailwind + متغيرات الثيم (CSS variables)
app/api/contact/route.ts    ← اختياري: استقبال نموذج التواصل
components/layout/Navbar.tsx | Footer.tsx | ThemeToggle.tsx
components/sections/Hero.tsx | About.tsx | Projects.tsx | Timeline.tsx | Skills.tsx | Contact.tsx
components/ui/GlassCard.tsx | Badge.tsx | SectionHeading.tsx | Counter.tsx | BrowserMockup.tsx
lib/data.ts                 ← كل المحتوى (نصوص/مشاريع/خبرات/مهارات) — مصدر حقيقة واحد
lib/types.ts | lib/motion.ts (variants مشتركة)
tailwind.config.ts | next.config.mjs | package.json | README.md
```

**قاعدة صارمة:** لا يُكتب أي نص عربي داخل مكوّن JSX مباشرة. كل المحتوى في `lib/data.ts` مع أنواع TypeScript صريحة، والمكونات تستهلكه عبر `map`. هذا يجعل التحديث لاحقاً بتعديل ملف واحد.

## 4) بنية الصفحة

**Navbar** — شفاف عند القمة ثم `backdrop-blur` + ظل عند التمرير. شعار «م ك» في مربع متدرّج. روابط: عني · الخبرات · المشاريع · المهارات · تواصل معي، مع تمييز القسم النشط (IntersectionObserver). زر تبديل الثيم، زر «تحميل السيرة الذاتية». قائمة جانبية (Drawer) للجوال تنزلق من اليمين، تُغلق بـ `Escape` وبالنقر خارجها، مع حبس التركيز (focus trap).

**Hero** — خلفية شبكية خافتة + كرتان ضوئيتان متحركتان (blur blobs) تحترمان `prefers-reduced-motion`. العنوان بخط ثقيل، وتحته سطر بتأثير كتابة يتنقل بين: «مهندس تطوير برمجيات» / «أخصائي أتمتة وذكاء اصطناعي» / «أستاذ تقانة معلومات». زرّان: «استكشف أعمالي» (ممتلئ متدرّج) و«تواصل معي» (محدّد/outline). عدّادات تبدأ عند دخول القسم للشاشة: **+٥ سنوات خبرة · +١٥ مشروعاً · +٥٠٠ طالب مُدرَّب · ٤ منصات منشورة**.

**About** — شبكة `md:grid-cols-3`: عمودان للنبذة والفلسفة المهنية، وعمود لبطاقة «لمحة سريعة» (الموقع · التعليم · اللغات · التوفر). أضف ٣ بطاقات مبادئ: «الكود يخدم المستخدم» · «الأتمتة تُحرِّر الوقت للتفكير» · «التعليم استثمار مضاعف».

**Projects** — شبكة `lg:grid-cols-2`، بطاقة زجاجية بحدّ متدرّج يضيء عند المرور، معاينة المتصفح أعلاها، ثم العنوان، ٣–٤ نقاط ميزات بأيقونة `Check`، شارات التقنيات، وزر «عرض مباشر» بـ `target="_blank" rel="noopener noreferrer"`. المشاريع بلا رابط تعرض شارة «منصة قائمة» بدل الزر — **لا تخترع روابط**.

**Timeline** — خط رأسي على يمين المحتوى (RTL) بتدرّج لوني، ونقاط متوهّجة تنبض عند الوظيفة الحالية. كل بطاقة تظهر بـ stagger عند الوصول. أدرج التعليم كآخر عنصر بلون مختلف.

**Skills** — أربع بطاقات كما في §3.

**Contact** — عمودان: نموذج (الاسم · البريد · الرسالة) بتحقّق فوري ورسائل خطأ عربية وحالات `idle/sending/success/error`؛ وبطاقات تواصل مباشر (واتساب · بريد · الموقع الجغرافي). إن لم يوجد باكند فعلي، اجعل الإرسال يفتح `mailto:` مُهيّأً أو رابط واتساب، ووضّح ذلك في `README` — **لا تُظهر رسالة نجاح كاذبة**.

**Footer** — الشعار، روابط سريعة، وسنة ديناميكية `new Date().getFullYear()`.

## 5) المواصفات التقنية الإلزامية

**RTL:** `<html lang="ar" dir="rtl">`. استخدم خصائص Tailwind المنطقية حصراً (`ps-*`, `pe-*`, `ms-*`, `me-*`, `start-*`, `end-*`) — ممنوع `pl/pr/left/right`. الأيقونات ذات الاتجاه (أسهم) تُعكس بـ `rtl:rotate-180`. حركات `translateX` في Framer Motion تبدأ من الجهة الصحيحة (`x: 40` للدخول من اليمين).

**الخط:** `next/font/google` مع **IBM Plex Sans Arabic** (بديل: Cairo أو Tajawal)، `display: 'swap'`، ومتغيّر CSS `--font-arabic` في `tailwind.config`. لا `@import` من داخل CSS.

**الأرقام:** أرقام عربية-هندية (١٢٣) في العدّادات والإحصاءات، وأرقام لاتينية في التواريخ التقنية والروابط والهاتف. طبّقها عبر `toLocaleString('ar-EG')` لا يدوياً.

**الثيم:** `class`-based dark mode، الحالة في `localStorage` + احترام `prefers-color-scheme`، مع سكربت مضمّن في `<head>` يضبط الـ class قبل الطلاء لمنع وميض الثيم (FOUC) و hydration mismatch. الألوان كمتغيرات CSS (`--bg`, `--surface`, `--accent`…) لا قيم مكتوبة داخل الفئات.

**Glassmorphism:** `bg-white/60 dark:bg-white/5` + `backdrop-blur-xl` + `border border-white/20 dark:border-white/10` + ظل ناعم. تأكد من **تباين نص ≥ 4.5:1** في الوضعين — الزجاج لا يبرّر نصاً باهتاً.

**الحركة:** Framer Motion فقط، `whileInView` مع `viewport={{ once: true, margin: '-80px' }}`، مدد ٠٫٣–٠٫٦ث و`ease: [0.22, 1, 0.36, 1]`. variants مشتركة في `lib/motion.ts`. **كل الحركات تتعطّل** تحت `prefers-reduced-motion: reduce`.

**الوصولية:** HTML دلالي (`header/nav/main/section/footer`)، تسلسل عناوين سليم (h1 واحد)، `aria-label` على الأزرار الأيقونية، حلقة تركيز مرئية `focus-visible`، رابط «تخطَّ إلى المحتوى»، وتنقّل كامل بلوحة المفاتيح.

**SEO:** `metadata` كامل (title template, description, keywords عربية) + Open Graph + Twitter Card + `alternates.canonical` + JSON-LD من نوع `Person` (الاسم، المسمّى، البريد، جامعة كردفان، العنوان).

**الأداء:** ‏`'use client'` فقط على المكوّنات التي تحتاجه فعلاً (الـ Navbar، العدّادات، الفلاتر، النموذج، تبديل الثيم) — البقية Server Components. صفر تبعيات خارج: `next, react, framer-motion, lucide-react, tailwindcss, clsx`. صفر طلبات شبكة وقت التشغيل. الهدف: Lighthouse ≥ ٩٥ في الأربعة.

**التجاوب:** Mobile-first. اختبر ذهنياً عند `360px / 768px / 1024px / 1440px`. لا تمرير أفقي عند أي عرض. مساحات لمس ≥ ٤٤px.

**السيرة الذاتية:** ضع `public/cv-maaz-karshoum.pdf` كعنصر نائب، واذكر في `README` أن على المالك استبداله بالملف الحقيقي.
