# دليل الإعداد — معرض الراقي الهندسي للأثاث والديكور

هذا الدليل يشرح كل شيء خطوة بخطوة. لا يحتاج خبرة برمجية.

---

## أولاً: تشغيل الموقع على جهازك (5 دقائق)

```bash
npm install
npm run dev
```

ثم افتح المتصفح على: <http://localhost:3000>

- الموقع للعملاء: `/`
- لوحة تحكم المدير: `/admin`
- كلمة المرور المبدئية للوضع التجريبي: **`admin1234`**

في هذه المرحلة يعمل الموقع كاملاً على **التخزين المحلي داخل متصفحك**، مع 12 قطعة تجريبية جاهزة.

> ⚠️ **مهم جداً**: في الوضع المحلي، المنتجات التي تضيفها محفوظة في متصفحك أنت فقط.
> العملاء على أجهزتهم **لن يروها**. لنشر منتجاتك للجميع، أكمل القسم التالي.

## ثانياً: تفعيل قاعدة البيانات السحابية (Supabase) — مجاناً

### الخطوة ١: إنشاء المشروع

1. ادخل إلى <https://supabase.com> واضغط **Start your project**.
2. سجّل الدخول بحساب GitHub أو بالبريد الإلكتروني.
3. اضغط **New project** واملأ:
   - **Name**: `alraqi-furniture`
   - **Database Password**: كلمة مرور قوية — **احفظها في مكان آمن**.
   - **Region**: اختر `Europe (Frankfurt)` أو `Middle East` — الأقرب للسودان.
4. اضغط **Create new project** وانتظر دقيقتين حتى يجهز.

### الخطوة ٢: إنشاء الجداول

1. من القائمة الجانبية اختر **SQL Editor**.
2. اضغط **New query**.
3. افتح ملف `supabase/schema.sql` من هذا المشروع، وانسخ **كل** محتواه.
4. الصقه في المحرر واضغط **Run** (أو `Ctrl+Enter`).
5. يجب أن يظهر جدول نتيجة يحمل: **✅ تم إنشاء قاعدة البيانات بنجاح**.

هذا الملف ينشئ:
- جدول المنتجات وجدول الإعدادات
- قواعد الأمان (RLS) التي تمنع أي شخص غيرك من التعديل
- مخزن الصور `product-images`

> **ملاحظة عن مخزن الصور**: في بعض المشاريع لا يملك المستخدم صلاحية
> تعديل `storage.objects`، فيتخطّى الملف هذا الجزء بأمان دون أن يُلغي
> إنشاء الجداول. إن ظهر تنبيه بذلك، أنشئ المخزن يدوياً:
> **Storage** ← **New bucket** ← الاسم `product-images` ← فعّل **Public bucket**.
> الجداول تكون قد أُنشئت بنجاح والموقع يعمل بصور الكتالوج المضمّنة في المشروع.

### الخطوة ٣: نسخ المفاتيح

1. من القائمة الجانبية: **Project Settings** ← **API**.
2. انسخ القيمتين:
   - **Project URL** → مثال: `https://abcdefgh.supabase.co`
   - **anon public** key → نص طويل يبدأ بـ `eyJ...`

> 🔒 **لا تنسخ مفتاح `service_role` إطلاقاً** ولا تضعه في المشروع. المفتاح الوحيد
> المسموح باستخدامه هو `anon`، وهو محمي بقواعد RLS.

### الخطوة ٤: وضع المفاتيح في المشروع

أنشئ ملفاً جديداً باسم `.env.local` في جذر المشروع (بجانب `package.json`) واكتب فيه:

```
NEXT_PUBLIC_SUPABASE_URL=https://ضع-هنا-رابط-مشروعك.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ضع-هنا-المفتاح-الطويل
```

> ملف `.env.local` لا يُرفع إلى GitHub — هذا مقصود لحماية بياناتك.

### الخطوة ٥: إنشاء حساب المدير

1. في Supabase: **Authentication** ← **Users** ← **Add user** ← **Create new user**.
2. أدخل بريدك الإلكتروني وكلمة مرور قوية.
3. **فعّل خيار `Auto Confirm User`** — مهم جداً، وإلا لن تستطيع الدخول.
4. اضغط **Create user**.

### الخطوة ٦: إعادة التشغيل

```bash
npm run dev
```

افتح `/admin` وسجّل الدخول بالبريد وكلمة المرور اللذين أنشأتهما.
ستجد في أعلى اللوحة شارة خضراء **☁️ متصل بـ Supabase** — تعني أن كل شيء يعمل.

## ثالثاً: ضبط بيانات معرضك

من **لوحة التحكم ← الإعدادات** غيّر:

| الحقل | ملاحظات |
|---|---|
| **رقم واتساب الطلبات** | الأهم — كل طلبات العملاء تصل إليه. اكتبه `+249xxxxxxxxx` أو `09xxxxxxxx` |
| رقم واتساب إضافي | اختياري، يظهر كخيار ثانٍ في صفحة التواصل |
| العنوان وأوقات العمل | تظهر في الذيل وصفحة التواصل |
| رمز العملة | الافتراضي `ج.س` — غيّره متى شئت |
| شريط الإعلانات | اتركه فارغاً لإخفاء الشريط الذهبي العلوي |
| روابط التواصل الاجتماعي | الحقل الفارغ يُخفي أيقونته |

ثم من **المنتجات** اضغط **🧹 مسح البيانات التجريبية** لحذف القطع الاثنتي عشرة التجريبية.

## رابعاً: إضافة قطعة أثاث

1. **لوحة التحكم ← إضافة قطعة**.
2. اكتب الاسم والسعر واختر القسم (الكود يُولَّد تلقائياً، ويمكن تعديله).
3. أضف الصور بإحدى طريقتين — **كلاهما متاح دائماً**:
   - **🖼️ من معرض الجهاز**: يفتح معرض صور هاتفك أو ملفات حاسوبك. يمكن اختيار عدة صور دفعة واحدة، أو سحبها وإفلاتها.
   - **📷 التقاط بالكاميرا**: يفتح كاميرا الجهاز مباشرة للتصوير الفوري.
4. لكل صورة يظهر خياران **مستقلان**:
   - **✨ تفريغ الخلفية** — اختياري تماماً.
   - **الحفظ كما هي** — ببساطة لا تضغط زر التفريغ. لا يُحمَّل أي نموذج ذكاء اصطناعي في هذه الحالة.
5. اضغط **إضافة القطعة**. تظهر للعملاء فوراً.

### ملاحظات على تفريغ الخلفية

- **أول استخدام فقط** ينزّل نموذج ذكاء اصطناعي بحجم عشرات الميجابايت. بعده يصبح سريعاً.
- يعمل داخل متصفحك بالكامل — صورك لا تُرسل إلى أي خادم خارجي.
- الصورة الأصلية تُحفظ دائماً، فيمكنك الضغط على **↩ الأصلية** للتراجع في أي وقت.
- إن كانت شبكتك ضعيفة، تجاهل الزر واحفظ الصورة كما هي — النتيجة النهائية تبقى ممتازة.
- أفضل نتيجة: صوّر القطعة أمام **خلفية بسيطة** وبإضاءة جيدة.

### ملاحظة على الكاميرا

المتصفحات لا تسمح بفتح الكاميرا إلا على **HTTPS** أو على `localhost`. عند النشر على
Vercel يكون الاتصال HTTPS تلقائياً فتعمل الكاميرا بلا مشاكل. إن ظهرت رسالة عن
"اتصال آمن"، استخدم الرفع من معرض الجهاز بدلاً منها.

## خامساً: النشر على الإنترنت (Vercel — مجاناً)

1. ارفع المشروع إلى مستودع GitHub.
2. ادخل <https://vercel.com> وسجّل بحساب GitHub.
3. **Add New** ← **Project** ← اختر المستودع.
4. في **Environment Variables** أضف المتغيرين نفسيهما من الخطوة ٤.
5. اضغط **Deploy**.

سيصبح موقعك متاحاً على رابط `https://اسم-مشروعك.vercel.app` مع HTTPS تلقائي.

## أسئلة شائعة

**هل تُنقل بياناتي المحلية تلقائياً إلى Supabase؟**
لا. التخزين المحلي والسحابي منفصلان. بعد تفعيل Supabase أعد إدخال منتجاتك مرة واحدة من لوحة التحكم.

**نسيت كلمة مرور المدير.**
من Supabase: **Authentication ← Users** ← اضغط على المستخدم ← **Reset password**.

**ظهرت رسالة "جداول قاعدة البيانات غير موجودة".**
لم تُشغّل ملف `supabase/schema.sql`. ارجع إلى الخطوة ٢.

**ظهرت رسالة "ليست لديك صلاحية لهذه العملية".**
انتهت جلستك. سجّل الخروج ثم الدخول مرة أخرى.

**كيف أغيّر ألوان الموقع أو أقسامه؟**
- الألوان: `tailwind.config.ts`
- الأقسام ونصوص البانر: `lib/constants.ts`
